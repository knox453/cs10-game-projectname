# One Long Day

A serious Arcade game about one difficult day living in poverty. Move around the neighborhood, enter each location, and make choices that affect patience, stability, grades, and family trust.

## Download

Mac:
[Download OneLongDay-mac.zip](https://github.com/knox453/cs10-game-projectname/releases/latest/download/OneLongDay-mac.zip)

Windows:
[Download OneLongDay-windows.exe]C:\Users\devnt\cs10-game-projectname\dist

## How to Play

Open the download for your computer. In the game, use WASD or arrow keys to move, press E near a location, and click choices when scenes appear.

## Build From Source

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the game:

```bash
python game.py
```
